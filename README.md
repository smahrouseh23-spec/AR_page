# Basic AR Component Showcase

Simple Web AR component showcase using Google's `<model-viewer>` web component.

## Features

- Loads `./assets/component.glb`
- Camera controls
- AR mode
- Auto-rotate
- Shadows and neutral lighting
- Student Tech Lab ELTE-inspired logo/color styling
- Kontron front rocker model selector
